# 📖 Manual de Cultura de la Especialidad de Programación 💻🎮

Este repositorio contiene las reglas, acuerdos, valores y filosofía de trabajo de la Especialidad de Programación AVB.

No es solo un reglamento. Es un documento vivo creado para que cada generación de estudiantes pueda conocer cómo trabajamos, cómo nos organizamos y qué esperamos de quienes forman parte de esta especialidad.

Los estudiantes pueden proponer mejoras mediante GitHub, usando issues, commits y pull requests.
